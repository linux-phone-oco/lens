# The Linux Phones lens

The grand view of the [linux-phone-oco](https://github.com/linux-phone-oco) family, declared as data
in [`lens.toml`](lens.toml): which projects it gathers, and the views that show them - how close we
are, features, devices, SoC families, tests, backlog, landscape, and what the work says. The
[Open Commons Observatory](https://open-commons-observatory.github.io/) discovers and renders it
(the specification is [ocoeco's section 8](https://github.com/open-commons-observatory/ocoeco/blob/main/SPEC.md)).
Fork it to make a lens of your own family of projects.
